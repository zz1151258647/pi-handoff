## 目标与范围

- 交付带版本和校验的 JS 运行包，正式安装不再依赖源码 Git 工作区。
- 包括：构建、产物隔离测试、安全本地安装、README、v2.0.1 tag 与 Release、当前用户安装切换和回退。
- 不包括：npm 发布、交接业务调整、Messenger/Subagents、更换或读取真实交接缓存、覆盖旧版本。
- 沿用已验收的两项补全、Tab 菜单和压缩纯计数；Pi SDK/typebox 由宿主提供。

## 当前行为规则

| 场景 | 操作 | 应有结果 | 异常边界 |
|---|---|---|---|
| 源码构建 | 执行构建命令 | 输出版本化 tgz 与 SHA256 文件，包内仅运行必要文件 | 构建不得修改用户配置/真实缓存，不纳入未跟踪文件 |
| 产物加载 | 解包到独立目录 | 清单指向 JS，Skill 完整，宿主可以加载并保持行为 | 不捆绑宿主 SDK/typebox，不依赖源码相对路径 |
| 安装 | 使用空的固定版本目录 | 只落入运行包，未启用前不改全局设置 | 非空目标拒绝，不覆盖用户文件 |
| 发布 | 创建 v2.0.1 tag/Release | 包及校验文件可下载并一致 | 不覆盖 v2.0.0，不发未通过测试的包 |
| 切换 | 备份后替换当前 handoff 包来源 | 仅启用一份，固定到 2.0.1 产物目录，其他设置不变 | 保留原 Git 仓库与回退信息，重载/新会话生效 |

## 完成标准

| ID | 如何判断完成 | 需要覆盖的层级 |
|---|---|---|
| AC-01 | 运行包版本 2.0.1，JS 入口与完整 Skill 存在，无 TS 源码、tests、Git、node_modules 或用户数据 | 构建与包内容自动检查 |
| AC-02 | 空目录安装成功，非空目录拒绝，构建/安装不改源码、设置或真实缓存 | 隔离文件系统自动检查 |
| AC-03 | 源码和解包 JS 均通过现有 15 组回归；真实 Pi loader 可加载产物，补全/消息展示/授权/计数保持不变 | 真实宿主组件自动检查，不调用模型 |
| AC-04 | v2.0.1 tag/Release 指向包含本版代码的提交；远端下载资产 SHA256 与本地构建一致 | 真实远端发布与下载回读 |
| AC-05 | 当前用户配置只替换 handoff 来源，固定目录安装通过加载验证、无重复启用；原来源/源码/缓存保留，回退入口明确 | 本机安装与配置回读；当前终端热重载另行说明 |
