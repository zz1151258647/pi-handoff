# v2.0.1 计划

## 版本定义

- **版本类型**：新能力。
- **目标**：Handoff 提供独立的预编译运行包、校验文件与安全安装方式，发布到 GitHub Release，并将当前用户安装从 Git 工作区切换到固定产物目录。
- **不做什么**：不改交接/接续授权、压缩纯计数、两项子菜单或模型材料；不改 Messenger/Subagents；不发布 npm；不覆盖旧 tag/Release，不删除源码与交接缓存。
- **完成标准**：规格 AC-01 至 AC-05 覆盖的构建、包内容、回归、远端下载校验与本机切换均有证据。
- **来源 / 前序版本**：2026-11-03 本会话用户明确选择“按 v2.0.1 实施”；前序为 v2.0.0，已验收修复基线为 dbc1c7e。
- **切出下一版本条件**：业务行为、安装平台范围或外部发布渠道发生独立变化时再请用户决定。
