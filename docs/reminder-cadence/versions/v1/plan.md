# v1 计划

## 版本定义
- **版本类型**：质量治理
- **目标**：减少较小上下文窗口中不必要的交接评估，同时保留大窗口兜底与阶段提醒。
- **不做什么**：不改变 pi 自动压缩阈值、不自动保存或新建会话、不按模型名称硬编码 GPT 特例。
- **完成标准**：小窗口规模阈值推迟；大窗口原行为保留；无新事实的暂缓默认不在下一轮反复评估；模拟测试覆盖上述情况。
- **来源 / 前序版本**：本次用户反馈及确认；仓库 v1.1.0。
- **切出下一版本条件**：需要改变阶段边界判断、压缩计数机制或业务交接流程时另议。
